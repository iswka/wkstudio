# 项目特性文档

## 核心功能

### 1. 用户认证系统

#### 用户注册
- ✅ 用户名唯一性验证
- ✅ 邮箱唯一性验证
- ✅ 密码 bcrypt 加密存储
- ✅ 参数格式验证
- ✅ 手机号码（可选）

#### 用户登录
- ✅ 用户名密码验证
- ✅ 用户状态检查
- ✅ JWT Token 生成
- ✅ Token 过期时间配置

### 2. 安全特性

#### 密码安全
- **加密算法**：bcrypt（成本因子：默认10）
- **密码要求**：6-20 个字符
- **存储**：只存储哈希值，不存储明文

#### JWT 认证
- **算法**：HS256
- **Payload**：用户ID、过期时间
- **默认有效期**：24小时（可配置）
- **自动验证**：go-zero 框架自动处理

#### API 保护
- **公开接口**：注册、登录
- **受保护接口**：用户信息、修改密码
- **认证机制**：Bearer Token

### 3. 数据库设计

#### 用户表 (users)

| 字段 | 类型 | 说明 | 索引 |
|------|------|------|------|
| id | BIGINT | 主键，自增 | PRIMARY |
| username | VARCHAR(50) | 用户名 | UNIQUE |
| password | VARCHAR(255) | 密码哈希 | - |
| email | VARCHAR(100) | 邮箱 | UNIQUE |
| mobile | VARCHAR(20) | 手机号 | - |
| status | INT | 状态(1:正常,0:禁用) | - |
| created_at | TIMESTAMP | 创建时间 | INDEX |
| updated_at | TIMESTAMP | 更新时间 | - |

#### 索引策略
- `username` - 唯一索引（登录查询）
- `email` - 唯一索引（注册验证）
- `created_at` - 普通索引（按时间查询）

### 4. API 接口

#### 公开接口

| 方法 | 路径 | 功能 | 认证 |
|------|------|------|------|
| POST | /api/auth/register | 用户注册 | ❌ |
| POST | /api/auth/login | 用户登录 | ❌ |

#### 受保护接口

| 方法 | 路径 | 功能 | 认证 |
|------|------|------|------|
| GET | /api/user/info | 获取用户信息 | ✅ |
| POST | /api/user/change-password | 修改密码 | ✅ |

### 5. 错误处理

#### 统一错误响应
```json
{
    "code": 400,
    "msg": "错误信息"
}
```

#### 常见错误码
- `200` - 成功
- `400` - 请求参数错误
- `401` - 未授权（Token无效或过期）
- `403` - 权限不足
- `404` - 资源不存在
- `500` - 服务器内部错误
